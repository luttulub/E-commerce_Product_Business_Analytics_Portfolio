# 이커머스 고객 행동 데이터 기반 퍼널·코호트·리텐션 분석 프로젝트

## 목표
SQL을 기반으로 이커머스 고객의 구매 행동과 주문·배송 경험을 분석하고,
퍼널, 코호트, 리텐션 및 재구매 지표를 통해 서비스와 비즈니스 개선안을
제안하는 데이터 분석 포트폴리오입니다.

## 진행 계획
- Olist 데이터 구조 및 품질 검증
- 핵심 비즈니스 지표 분석
- 고객 구매 행동 및 재구매 분석
- 주문·배송 퍼널 분석
- 코호트 및 리텐션 분석
- 배송 경험과 리뷰 점수 관계 분석
- Tableau 대시보드 및 최종 보고서 제작
